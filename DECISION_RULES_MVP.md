# DECISION_RULES_MVP.md
# Decision Engine Rules — MVP Edition
# Путь: /DECISION_RULES_MVP.md

## Назначение
Формирует окончательное решение ("ALLOW" или "DENY") на основе:
1. политики,
2. уровня чувствительности действия,
3. базовых правил безопасности.

## Что делает
- Принимает результат Policy Engine.
- Применяет бизнес-правила (sensitivity).
- Выдаёт финальное решение для Router.

## Что получает (вход)
- действие `action`
- результат policy (`allow` / `deny`)
- дополнительные признаки (например, contains delete)

## Что отдаёт (выход)
Финальное решение:
- `ALLOW`
- `DENY`

## MVP правила
1. Если `policy = deny` → DENY  
2. Если действие содержит `delete` → DENY  
3. Если действие начинается с `db.` → DENY  
4. Иначе → ALLOW
