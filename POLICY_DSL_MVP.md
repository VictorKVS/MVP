# Policy DSL — MVP Edition
# Путь: /POLICY_DSL_MVP.md

## Назначение файла
Определяет минимальный декларативный язык политик, который решает:
- какие действия разрешены,
- какие запрещены,
- что делать по умолчанию.

Policy Engine использует эти правила при каждом запросе.

## Что делает
- Описывает синтаксис правила.
- Задает действия allow/deny.
- Определяет правило по умолчанию — deny.

## Что получает (вход)
Action из UQP запроса, например:
ticket.get
ticket.list
ticket.delete


Engine сравнивает action с правилами.

## Что отдаёт (выход)
- `allow` — действие разрешено
- `deny` — действие запрещено

Пример:


allow ticket.get
allow ticket.list

deny .delete
deny db.

default deny


## Ограничения MVP
- Только точные allow/deny.
- Нет условий по ролям.
- Нет контекстных политик.
