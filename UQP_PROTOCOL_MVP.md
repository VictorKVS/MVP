# UQP_PROTOCOL_MVP.md
# Universal Query Protocol — MVP Edition
# Путь: /UQP_PROTOCOL_MVP.md

## Назначение файла
Документ описывает минимальный протокол UQP (Universal Query Protocol), используемый для общения агента с UAG_MVP.  
Протокол определяет структуру входного запроса и выходного ответа.

## Что делает
- Описывает форматы запроса и ответа.
- Определяет обязательные поля.
- Задает минимальные правила обработки ошибок.
- Формирует основу для API Gateway и Router.

## Что получает (вход)
Запрос агента в формате JSON:
- `action` — имя операции.
- `params` — параметры действия.
- `context` — служебные данные (минимально используются).

Пример входа:
```json
{
  "action": "ticket.get",
  "params": { "id": "TCK-123" },
  "context": {}
}

Что отдаёт (выход)

стандартный успешный ответ,

либо ошибку в унифицированном формате.

Пример успешного ответа:

{
  "status": "success",
  "data": { ... }
}


Пример ошибки:

{
  "status": "error",
  "error": {
    "code": "POLICY_DENY",
    "message": "Operation is not allowed"
  }
}

Ограничения MVP

Один провайдер: Ticket API.

Две операции: get и list.

Без транзакций, стриминга и сложных структур.
